# Application note

Subject: Geospatial/data-engineering pilot — municipal street-light network

Hello,

I am interested in the scoped municipal street-light data pilot. I built a
small reproducible project using public Vancouver and District of North
Vancouver data. It normalizes GeoJSON and File Geodatabase sources through
YAML-driven Python/GeoPandas ETL, preserves source provenance, runs geometry and
network QA, and produces QGIS exhibits.

The project includes a real DNV conduit-network trace to reachable and
unreachable poles. I also documented a pole-mediated connection and a 0.0486 m
endpoint discrepancy rather than hiding it with arbitrary snapping. Vancouver
was carried through normalization and QA, then intentionally stopped because
the public exports lack a shared connectivity identifier. The project records
that electrical capacity cannot be calculated without panel and circuit
records.
