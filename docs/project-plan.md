# Project plan

Small, targeted application project. Advance when evidence satisfies each stopping condition; report blockers instead of fabricating connectivity.

## Phase 1

Inspect the real public data.

**Stopping condition:** I understand the source layers well enough to explain how network connectivity appears to be represented.

## Phase 2

Build one real DNV pole-to-service-panel trace.

**Stopping condition:** I can explain nodes, edges, connectivity rules, traversal, validation, and one failure mode.

## Phase 3

Normalize Vancouver and DNV.

**Stopping condition:** Both can be represented through one minimal common schema without destroying source provenance.

## Phase 4

Run QA and document limitations.

**Stopping condition:** I know which conclusions are supported and which are not supported by the public data.

## Phase 5

Package for application.

**Stopping condition:** A reviewer can open the repository and understand the problem, pipeline, trace, QA, and limitations quickly.

GIS and network choices require owner decisions supported by inspection evidence; see [assumptions.md](assumptions.md). P2 work is deferred until after application.
