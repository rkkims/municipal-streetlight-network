# Supplemental data request log

Use this log to record information that could be requested when public
street-light GIS data is insufficient for network interpretation or candidate
screening. Identify the study area or asset IDs for each request.

## Candidate records to request

1. Service-panel, service-box, and power-supply locations, including stable
   asset identifiers.
2. Circuit or network identifiers linking panels, conduits, fittings, and
   poles.
3. Conduit endpoint, junction, vault, or fitting connectivity records.
4. Electrical panel ratings, circuit ratings, and available or spare capacity,
   if maintained and releasable.
5. Pole height, material, ownership, structural rating, and attachment
   restrictions.
6. Heritage, right-of-way, sightline, or other municipal exclusion areas.
7. Dataset metadata: source date, update frequency, CRS, positional accuracy,
   field definitions, and known limitations.
